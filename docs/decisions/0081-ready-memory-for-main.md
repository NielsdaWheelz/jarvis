## decision

after the existing bounded canonical publication, main freezes the admitted
cutoff and obtains the same immutable ready-view value as external readers.
the library owns selection, clipping, fitting and rendering. count coverage and
admitted-backlog metadata inside the existing 128,000-byte historical frame.

entry. remove main's required-compaction path; add no mode or fallback.

report actual `[0,through)` coverage and the frozen admitted bound. `through`
may be zero or below construction progress when only an older prefix fits.
neither case means empty history. keep the admitted cutoff, not `through`, for
archive/search/open access. existing missing/unsupported/read-error semantics
remain; finding or recalling omitted material is not guaranteed.

keep exact active canonical inputs, the existing bounded receipt context,
current-owner permits, action/read barriers, native sealing and mid-turn steering
unchanged. freeze historical orientation for the running turn. canonical
publication and database errors still block rather than become empty success.

the existing idle worker continues full compression and indexing. retain strict
full preparation for dreaming and maintenance where their contracts require it.
repair construction failures independently. add no daemon, timer, fairness
mechanism, database schema, grant, model substitution, raw-tail window or replay
journal. rotate main's owning compatibility revision, the affected `memory.view`
implementation revision and the changed dependency pins; leave other revisions
unchanged.

## trade-off and qualification

historical orientation can remain stale or empty indefinitely if construction
parks or continuous foreground work prevents catch-up. omitted corrections and
preferences may not be recalled, even though retained originals remain available
through existing archive reads when identified. foreground availability takes
precedence over automatic historical completeness. no throughput or freshness
guarantee is added.

use f2's temporary end-to-end red/green/refactor and independent review. prove
nonblocking main dispatch, truthful empty/partial coverage, frozen admitted read
scope beyond the ready prefix, unchanged operative inputs/recovery, complete
bounded shared views and unchanged strict dreamer/maintenance preparation. then
delete the new probes. source proof, installed journey and final reset remain
distinct; this decision waives none of f2's effects or recovery acceptance.
