# 0120 · files in google drive

**accepted implementation target · 2026-11-26.** the owner selected one private imports folder, an independent human reader and locally acknowledged pending uploads. isolated live qualification is authorized in the test project with synthetic files. installation and real-account use are separate.

## product contract

google drive owns personal documents, uploads, selected mail attachments and downloadable deliverables. jarvis keeps the ids needed for conversation and work. an existing drive file stays at its existing id. a new file gets its intended name and parent on creation. jarvis may inspect eligible files as the task requires. the owner can browse without starting a turn. private git continues to own runnable helpers, interactive html source and the existing revision-pinned publisher.

send a tax pdf from the phone. the chat receipt means jarvis has the upload. main may inspect it, choose the tax-year folder, file it once, and put the same item in chat and the todo result. editing the pdf in drive changes what both links open. an unavailable page says so. permanent deletion can break the link. filing organizes new items at creation. there is no drive mirror, sync daemon, discuss mode, custom document editor or background reorganization.

this replaces r2 document custody in [slice 5](../attachments-and-durable-originals.md), the original-byte viewer in [0087](0087-private-web-home.md), and the retained-file portions of [0101](0101-outgoing-mail-attachments.md) and [0107](0107-google-workspace.md). [0105](0105-native-android.md) owns handset authentication and todo results, [0116](0116-chat-composer-attachments.md) owns local drafts and explicit send, and [0117](0117-inline-todo-viewer.md) owns the todos tab. the immutable facts are what was received, sent or observed at the time. a document link names the current file. document backup has a [separate future issue](../issues/drive-document-backup.md). postgres recovery has its existing independent contract.
