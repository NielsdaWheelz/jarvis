# codex history and shell evidence

the selected codex 0.171 app server omits recent inter-agent mail and blocking
question answers from both public history projections. a terminal wait report
and an async answer admitted as user text have public evidence. the live jarvis
stream also exposes typed agent mail. native logs remain the source for other
recoverable detail. lost sessions can leave no recoverable evidence.

in a bounded macbook sample on november 23, 642 recent files with native
consumed-mail metadata across three homes contained 14,401 distinct confirmed
plaintext delivery ids, including 2,675 terminal delivery ids. 98 parent
conversations had such mail. these counts show the scale of the source gap.
they do not measure newly lost originals or represent the full corpus.

the stock command result exposes `aggregatedOutput` and `exitCode`. the server
drops its internal truncation metadata before emitting that result. archive
`reported` means the provider reported text. the archive cannot assert upstream
completeness or infer a count from a marker the command itself could print.

resolve with a qualified public source that exposes the missing facts. prove a
typed blocking answer, two distinct deliveries of the same words and structured
shell truncation through the real provider. keep the raw source-read boundary.
