# personal agent behavior remains unverified

status: open evidence gap, recorded 2026-11-14. this is not an implementation
blocker or a new standing qualification gate.

## problem and impact

the [competitive research](../research/personal-agents-2026-11/README.md) establishes
documented features and disclosed mechanisms, but includes no authenticated
competitor trials. it cannot rank actual completion reliability, attention saved,
background cost, memory quality or recovery after interruption. using the feature
matrix as such a ranking could misdirect jarvis's later roadmap.

## evidence and remaining limits

all five dossiers distinguish vendor contracts, demonstrations, reported
experiences and unknown internals. product-specific gaps are retained there.
no common task set was executed, and production journals, approval binding and
effect reconciliation are mostly undisclosed. some current features also depend
on region, plan or rollout. more marketing material will not close this gap.

## what would resolve it

before making a comparative performance claim, run the relevant same-owner
journeys on accessible products and record the exact date, plan, configuration,
inputs, interventions, actual results and costs. use synthetic or explicitly
authorized material and separately authorize any external communication or
purchase. only test failures that bear on a proposed decision; no general
benchmark platform is required.

if access is unavailable, retain the affected result as unknown and choose
jarvis's behavior from its own requirements. remove this issue when the later
roadmap review has either obtained the necessary observations or explicitly
closed the comparison without making unsupported performance claims.

blockers: account access and any trial-specific external authority were outside
this research pass. hidden implementation details may remain permanently private.
